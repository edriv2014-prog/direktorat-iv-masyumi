
# Direktorat IV - Seni Budaya & Content Kreasi - KAPPU DPP Partai Masyumi

Next.js 14 siap deploy ke Vercel.

## Cara Deploy ke Vercel (1 menit)
1. Upload folder ini ke GitHub (buat repo baru `direktorat-iv-masyumi`)
2. Buka https://vercel.com > Add New Project > Import GitHub repo
3. Klik Deploy — selesai, langsung dapat link https://direktorat-iv-masyumi.vercel.app

Atau via CLI:
```
npm i -g vercel
vercel
```

## Cara Jalan Lokal
```
npm install
npm run dev
```
Buka http://localhost:3000

## Struktur
- app/page.tsx = semua konten 9 program (Program/Contoh/Misal)
- Mudah edit: tinggal ganti teks di array `pillars`
